# 💬 Chat Manager

Современное одностраничное веб-приложение для управления чатами с красивым и отзывчивым интерфейсом.

## 📋 Описание

**Chat Manager** — это интерактивный интерфейс мессенджера, реализованный в виде единого HTML-файла. Приложение имитирует функционал настоящего чата с возможностью переключения между собеседниками, отправки и получения сообщений, а также автоматическими ответами.

## ✨ Особенности

### 🎨 Дизайн и Интерфейс
- **Современный градиентный дизайн** с использованием фиолетово-синей цветовой схемы
- **Анимированные элементы**: плавное появление контейнера, анимация сообщений, пульсирующий индикатор онлайн-статуса
- **Адаптивная вёрстка** с поддержкой мобильных устройств (responsive design)
- **Кастомизированные скроллбары** для эстетичного отображения
- **Эффекты при наведении**: увеличение аватарок, тени, трансформации элементов

### 🚀 Функциональность
- **Список чатов** с отображением последнего сообщения
- **Переключение между собеседниками** с подсветкой активного чата
- **Отправка сообщений** через кнопку или клавишу Enter
- **Автоматические ответы** от собеседников через случайный промежуток времени (2-4 секунды)
- **Временные метки** для каждого сообщения
- **Автоскролл** к последнему сообщению
- **Индикатор онлайн-статуса** с анимацией пульсации

## 📖 Использование

### Навигация
1. **Выбор чата:** Кликните на любой чат в левой панели для начала общения
2. **Просмотр сообщений:** История переписки отображается в центральной области
3. **Отправка сообщения:**
   - Введите текст в поле ввода внизу
   - Нажмите кнопку **"Отправить"** или клавишу **Enter**

### Поведение приложения
- При отправке сообщения оно мгновенно появляется в чате
- Через 2-4 секунды приходит автоматический ответ от собеседника
- Список чатов обновляется с отображением последнего сообщения
- Активный чат подсвечивается фиолетовой рамкой

### Структура данных

Приложение использует массив объектов `chats` для хранения данных:

```javascript
{
    id: 1,                    // Уникальный идентификатор
    name: 'Александр Петров', // Имя собеседника
    avatar: 'АП',             // Инициалы для аватарки
    messages: [               // Массив сообщений
        {
            text: 'Привет!',  // Текст сообщения
            sent: false,      // Отправлено ли нами (false = входящее)
            time: '10:30'     // Время отправки
        }
    ]
}
```

### Основные функции JavaScript

| Функция | Описание |
|---------|----------|
| `initChatList()` | Инициализирует и отображает список всех чатов |
| `selectChat(chatId)` | Выбирает активный чат и загружает сообщения |
| `displayMessages(messages)` | Отображает сообщения с каскадной анимацией |
| `addMessageToDOM(text, sent, time)` | Добавляет отдельное сообщение в DOM |
| `sendMessage()` | Обрабатывает отправку нового сообщения |
| `scrollToBottom()` | Прокручивает контейнер к последнему сообщению |
| `getCurrentTime()` | Возвращает текущее время в формате ЧЧ:ММ |
